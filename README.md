# YouTube Oldest Comments

Adds an "Oldest" option to YouTube's comment sort menu. When selected, it sorts the currently loaded comment threads from oldest to newest.

## Install (Chrome/Edge)
1. Open `chrome://extensions`
2. Enable Developer mode
3. Click "Load unpacked" and select this folder

## Usage
1. Open a YouTube video
2. Open the comment sort dropdown
3. Click "Oldest"

## Notes / Limitations
- The sort is client-side and only applies to comments that are currently loaded in the page. Scroll to load more comments for a more complete oldest order.
- Sorting uses the relative time text (e.g. "2 years ago") and approximates months/years.
- Currently optimized for English UI text.
